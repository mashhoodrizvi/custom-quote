ATLAS CUSTOM QUOTE BUILDER

WHAT THIS PAGE DOES
- Starts with no pre-written work descriptions.
- Description rows contain: Add item, Quantity, Unit price and Amount.
- The Add more item button creates another priced description row.
- Supply rows are text only and have their own Add more supply button.
- The PDF shows supply text in a separate bold Supply row below the priced items.
- Includes GST, an editable 5% deposit, the Atlas terms and the latest business details from the supplied August 2026 sample.
- Works on desktop and mobile, including the mobile navigation menu.

FILES TO UPLOAD
Upload every file in this folder to the root of the GitHub repository. Do not upload the ZIP file itself.

RECOMMENDED GITHUB REPOSITORY NAME
atlas-custom-quote

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository named atlas-custom-quote.
2. Upload all seven files from this folder to the main branch.
3. Open Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select main and /(root), then Save.
6. The page address will be:
   https://mashhoodrizvi.github.io/atlas-custom-quote/

CONNECT THE NEW QUOTE MENU IN THE OTHER ATLAS WEBSITES
In index.html for atlas-web, atlas-portal and atlas-renovation-portal, set the New Quote link in both the desktop and mobile menus to:

https://mashhoodrizvi.github.io/atlas-custom-quote/

IMPORTANT
Keep jspdf.umd.min.js and jspdf.plugin.autotable.min.js in the repository. They are required for the Download quotation PDF button.
